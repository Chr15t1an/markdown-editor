Markdown Editor

A free, open markdown editor for Mac

I wanted Typora's one-pane editing without the price tag, so I built a small native version. Markdown renders in place as you type, and any folder you drop on it opens as a file tree. No account, no vault.

Install with Terminal

Paste this into Terminal. It downloads v{{VERSION}}, checks the zip’s SHA-256, installs Markdown Editor to Applications and opens it. No Open Anyway step.

curl -fsSL https://markdown.chri5tian.com/install.sh | bash

Want to read it first? curl -fsSL https://markdown.chri5tian.com/install.sh | less

Inline editing

Headings, bold, links, lists, code and tables render as you type. One pane, no preview toggle.

Drop a folder to open it

Drag any folder onto the window or the Dock icon. Your notes stay plain .md files where they are.

Free and open

No price, no account, no tracking. The source is MIT-licensed. If you turn on update checks, the app asks this site once a day for the latest version number — like any web request, the site sees your IP address; nothing else is sent.

Prefer a normal download?

Use Download the zip above. The app is signed ad-hoc, not with an Apple Developer ID, and not notarized, so macOS blocks the first launch of a downloaded copy. You allow it once:

  1. Unzip the download (Safari may do this for you) and move Markdown Editor to Applications.
  2. Double-click it. macOS shows “Markdown Editor” Not Opened. Click Done, not Move to Trash.
  3. Open System Settings › Privacy & Security and scroll down to Security. Next to “Markdown Editor” was blocked to protect your Mac, click Open Anyway. The button shows for about an hour after you try to open the app.
  4. Confirm in the warning that follows, then enter your login password or use Touch ID.

After that it opens like any other app.

Please don’t paste xattr commands from other sites. The Terminal install above is the supported way to skip the Open Anyway step, and it checks the SHA-256 of the exact zip before installing anything.
